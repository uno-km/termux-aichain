termux-aichain

Sovereign Zero-Dependency AI Chaining and Agent Framework for Termux & Android Edge

1-Line Quick Installation

Install the official package directly into your runtime:

pip install termux-aichain
# or for Node.js:
npm install @termux-ai/chain

The Engineering Challenge

Mainstream AI frameworks (LangChain, LlamaIndex, CrewAI) introduce 80+ heavy dependencies, 250MB+ RSS overheads, and frequent compilation failures on ARM Android devices.

The Architectural Breakthrough

Engineered under the Zero-Heavy-Dependency doctrine: Pure Python stdlib and pure Node.js ESM orchestration for local llama-server, BitNet 1-bit models, state graphs, and native Termux hardware APIs.

Key Capabilities & Built-in Hardening

Zero External Heavy Dependencies

Pure Python standard library and pure Node.js ESM. Cold start import in under 18ms with less than 280KB disk footprint.

StateGraph & ReAct Engine

Deterministic cyclic state machines and autonomous tool-calling loops (LangGraph lightweight alternative).

SQLite Long-Term Memory

Persistent entity key-value storage and pure cosine vector search without ChromaDB or NumPy.

1-Line REST & SSE Server

Exposes any agent or chain over local mobile WiFi with Server-Sent Events without FastAPI overhead.

CLI Tree Tracer & TPS Meter

Hierarchical ANSI tree visualization, millisecond latency profiling, and token throughput meters.

Native Android Hardware Toolkit

Direct tool-calling wrappers for Termux-API (battery status, sensors, GPS location, STT, TTS, vibration).

Canonical Usage Example

from termux_aichain import (
    BitNetChat,
    create_react_agent,
    get_default_device_tools,
    Tracer,
    HumanMessage
)

# 1. Connect to local 1-bit or GGUF LLM
llm = BitNetChat(base_url="http://127.0.0.1:8088/v1", model="bitnet-b1.58-3b")

# 2. Compile ReAct Agent with native Android device tools
agent = create_react_agent(model=llm, tools=get_default_device_tools())

# 3. Profile execution with local CLI tracer
tracer = Tracer("EdgeMobileRun")
with tracer.trace("AgentExecution"):
    result = agent.invoke({"messages": [HumanMessage(content="Check battery and sensor status.")]})

tracer.finish()
tracer.print_tree()
print("Agent Output:", result["messages"][-1].content)

import {
  PromptTemplate,
  StateGraph,
  MicroVectorStore,
  serve
} from "@termux-ai/chain";

const prompt = PromptTemplate.fromTemplate("Edge Task: {task}");
const server = serve(prompt, { host: "0.0.0.0", port: 8080 });
