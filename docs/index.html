Termux-AIChain

Ultra-Lightweight Zero-Dependency AI Chaining & Autonomous Agent Framework for Android Termux

1-Line Quick Installation

Install the official package directly into your runtime:

pip install termux-aichain
# or:
npm install termux-aichain

The Engineering Challenge

Heavy agent frameworks (LangChain, LlamaIndex) require hundreds of bloated dependencies, causing package conflicts and OOM crashes on mobile Termux.

The Architectural Breakthrough

Provides pure zero-dependency DAG execution, structured prompt chains, and deterministic tool dispatching in <50KB footprint.

Key Capabilities & Built-in Hardening

Deterministic 0-Drift Output

Bit-exact floating-point precision verified across heterogeneous ARM64 & WebGPU hardware.

Zero Cloud Egress Architecture

Operates 100% on the local client without external network telemetry leaks.

Memory Leakage Protection

Weakref lifetime management preventing GPU VRAM / system RAM leaks.

Canonical Usage Example

from termux_aichain import Chain, Agent
agent = Agent(model='termux-bitnet')
chain = Chain([agent])
print(chain.run('Summarize task'))
import { Chain, Agent } from 'termux-aichain';
const agent = new Agent({ model: 'termux-bitnet' });
const chain = new Chain([agent]);
const res = await chain.run('Summarize task');
